Attack lab

Three designs store the same eight rental events. Pick something a dishonest administrator might do, then see which designs notice. Everything runs in your browser, with fresh keys created when the page opened.

The attacker has full access to the database and holds the server's signing key. The attacker does not have the tenant's or the landlord's private key.

This browser cannot create the Ed25519 keys the lab needs. Open the page in a recent Chrome, Edge, Safari or Firefox.

All attacks at a glance

This is a simulation under the same threat model as the project report. It shows what each design can and cannot detect without outside help. It is not an accuracy rate and not a claim of real-world security. Deleting the newest entries leaves a shorter chain that still looks valid in every design, so only a saved receipt catches it.
